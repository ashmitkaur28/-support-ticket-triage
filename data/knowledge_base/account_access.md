# Account Access & Security

Password resets are self-serve via the "Forgot Password" link and expire
after 1 hour.

If a customer reports suspicious account activity (unauthorized purchases,
changed email/password they didn't request), this is high urgency: lock
the account immediately and escalate to the security team.

Two-factor authentication issues (lost device, lost backup codes) require
identity verification via the email on file plus one additional piece of
account info (last order ID or billing zip).
